# Azure Two-Tier Student Management System

## Project Overview
A cloud-based Student Management System built using Flask,
HTML, CSS, JavaScript, and Azure Database for MySQL.

## Technologies Used
- Microsoft Azure
- Ubuntu Linux VM
- Python Flask
- HTML
- CSS
- JavaScript
- Azure Database for MySQL
- Git and GitHub

## Features
- Add student details
- View student records
- Delete student records
- Store student data in Azure MySQL
- Web-based user interface

## Run Locally

1. Install dependencies:
   pip install -r requirements.txt

2. Configure database environment variables:
   DB_HOST
   DB_USER
   DB_PASSWORD
   DB_NAME

3. Run the application:
   python app.py

4. Open:
   http://127.0.0.1:5000/
